# BrowserClaw Plugin for Codex & ChatGPT

Official Codex & ChatGPT plugin for **BrowserClaw** — High-efficiency, zero-hallucination Chrome browser control and automation.

## Features

- **100% Session & Auth Reuse**: Retains your active Google, GitHub, and enterprise SSO sessions without re-logging in.
- **Dual-Engine Control**: 1-based pruned accessibility DOM tree (slashing tokens by 85%+) with 1:1 CSS viewport visual coordinate fallback.
- **Code-Driven Chained Execution**: Supports running complex multi-step forms and interactions through in-page `mcp.*` methods within a single tool roundtrip.
- **Industrial Reliability**: Full Shadow DOM penetration, modal dialog self-healing interception, and Click Probe physical/synthetic double assurance.

## Installation

Add this marketplace in your Codex/ChatGPT environment:

```bash
codex plugin marketplace add https://github.com/GoldenLoaf24h/browserclaw
```

Then install the **BrowserClaw** plugin:

```bash
codex plugin install browserclaw
```
